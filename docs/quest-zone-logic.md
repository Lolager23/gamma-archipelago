# Native quest-restricted northern travel

Fresh generations default to `quest_zone_logic=1`. The active Dev baseline's
northern psi script is lethal to Free Stalkers in story mode until both X16's
Miracle Machine and Radar/X19's Brain Scorcher are disabled. A calibrated helmet
alone does not grant safe access. The catalogue records the inspected northern
maps and native info portions; the PDA reads those facts without granting them.

The world creates local shutdown events for every goal, including exploratory
and pilot goals, because northern map checks may still be enabled. These events
consume no network checks or reward slots. The Scorcher event inherits the
Living Legend shutdown check's cumulative regional, PDA, combat and quest-key
requirements, including Agroprom and its underground. Keys cannot bootstrap their
own prerequisite chain through a northern arrival check. The actual game still
requires completing its native quests; solver events do not complete them.

The sparse exploration fallback now queries the actual AP access graph. Keyed
introductory Living Legend checks use general restrictive fill. Late-only story
categories do not masquerade as an opening. A maps-only seed with all zone keys
and a locked PDA needs another reliable category, a starting PDA or an adjacent
starting key; otherwise it has no spare reward opportunity before the PDA becomes
mandatory for northern quest progression. Invalid configurations fail explicitly.

Omitted old fields mean zero and retain previous configuration digests and wire
records. Old archives retain their original placements and assumptions. Fresh
bundles must be generated together; changing a live seed's settings is unsupported.
Disabling the logic requires a matching native setup without these quest/psi
restrictions. Supported AP starts force story mode while this contract is enabled.

The New 04 archive placed Agroprom's key at Generators. Its old graph reported
completion because it omitted the northern shutdown gates. A regression now
withholds Agroprom while supplying the other items and confirms that Scorcher and
Generators remain unreachable. Restoring the key opens the route. The archive,
source inventories and hashes remain private outside Git.

Native acceptance is not run and belongs to Owen. Verify a fresh AP start, PDA
blocked reasons before/after each shutdown, and travel after both shutdowns.
No current game, profile, save, session or developer-panel file is changed by
this source increment. Class-based equipment requirements follow separately in
[the tiered progression plan](tiered-progression-plan.md).
