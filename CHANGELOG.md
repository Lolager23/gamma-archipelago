# Change log

## 1.0.0rc1 — private, unaccepted candidate

- Implement fourteen check categories and seven reward categories behind
  independent APWorld options, with finite published IDs and validated manifests.
- Add calibrated protection, Scorcher shutdown, Strelok encounter, Living Legend
  completion and the frozen five-lab tour as distinct goals.
- Add initial omissions, AP equipment permissions, exclusive orange psi claims,
  local zone-key exploration chains and optional previewed settlement trips.
- Add named PDA transfers, no-PDA queues, durable checks and bounded restart
  recovery; retain supported legacy pilot and expanded-seed formats.
- Add strict ID typing, bounded plain save validation, refused-save persistence,
  pending creation markers, isolated CLI imports and companion packaging.
- Add six presets, 6,000 seeds per verifier run, category combinations, real
  mixed-game server/restart cases, coverage gates and Windows/Linux CI.

APWorld metadata version is 1.0.0; companion version is 1.0.0rc1. No IDs are
recycled and no public v1 tag/release is created. Engine acceptance, independent
review and the owner's licence decision remain pending.
